## 1. 快速开始

### 1.1 系统概述

个人记账系统是一款轻量级 Web 记账应用，专为研究生/青年群体设计。你可以通过浏览器在电脑或手机上随时使用。

**核心设计理念**：极简记录、数据可视、不制造焦虑——看见即改变。

### 1.2 基本概念速览

在开始使用之前，先了解几个核心概念：

| 概念 | 说明 |
|------|------|
| **日常预算** | 月度总预算减去备用金后，用于日常消费的额度 |
| **备用金** | 独立于日常预算的储备额度，专门覆盖大额/应急消费 |
| **费用来源** | 每笔消费需要选择来源——"日常开支"或"备用金" |
| **冲动消费** | 用户自行标记的后悔型消费，影响连续无冲动天数 |
| **大宗消费** | 单笔 ≥ ¥100 的消费，系统会自动建议标记 |
| **连续无冲动天数** | 连续多少天没有发生冲动消费 |

### 1.3 导航说明

底部导航栏：

| 导航 | 图标 | 功能 |
|------|------|------|
| 首页 | 🏠 | 仪表盘，核心指标一览 |
| 账单 | 📋 | 账单列表，支持筛选和编辑 |
| 看板 | 📊 | 宏观资产看板，图表分析 |
| 成就 | 🏆 | 成就墙，徽章收集 |
| 物价 | 🔍 | 物价雷达，价格追踪 |

主要功能页面可通过首页卡片点击或底部导航进入。

## 2. 首页仪表盘

打开系统后进入首页，一目了然地看到你的财务状况：

### 2.1 核心指标卡片

首页顶部显示"本月已过 X 天，剩余 X 天"，之后是 6 张核心指标卡片。

#### 🔥 连续无冲动消费

- 显示当前连续多少天没有发生冲动消费
- 目标：30 天
- 进度条显示当前进度
- 点击卡片进入详情页，可查看 60 天热力图

#### 📊 日常消耗进度

- 显示格式：¥已花 / ¥日常有效预算
- 进度条颜色含义：
  - 绿色（<50%）：安全区
  - 橙色（50%-80%）：注意区
  - 红色（80%-100%）：警戒区
  - 深红（>100%）：透支区
- 正常状态显示"今日可用 ¥XX.XX"
- 透支状态显示"⚠️ 本月日常已透支 ¥XX.XX"
- 点击卡片进入预算详情页，查看每日额度变化曲线

#### 💧 备用金

- 显示格式：¥剩余 / ¥总额
- 颜色含义：
  - 蓝色：安全
  - 橙色：不足 50%
  - 灰色：已耗尽
  - 红色：已透支
- 点击卡片进入备用金详情页

#### ⚠️ 警示看板

- 显示最近 7 天内的大宗消费/冲动消费记录
- 红色 🔴 = 冲动消费，黄色 🟡 = 大宗消费
- 最多显示 5 条
- 点击进入账单列表

#### 🔍 物价雷达

- 显示本月涨幅最大的 3 个物品
- 展示涨跌趋势（📈/📉）和变化百分比
- 点击进入完整物价看板

#### 🏆 最新成就

- 显示最近解锁的 3 枚徽章
- 底部显示已解锁数量 / 总数量
- 点击进入成就墙页面

## 3. 记账功能

### 3.1 记一笔

从首页底部「+ 记一笔」按钮进入记账页面。

**操作步骤**：

1. **选择消费板块**：日常饮食 / 其他消费
2. **选择费用来源**：日常开支 / 备用金（默认日常开支）
3. **输入金额**：直接输入数字，也可使用快捷按钮（¥15、¥25、¥50、¥100）
4. **选择日期**：默认为今天，可回溯修改
5. **（可选）填写备注**：如"外卖-黄焖鸡"
6. **（可选）标记标签**：
   - 大宗消费：单笔≥¥100 时系统建议标记
   - 冲动消费：标记为后悔的冲动支出
7. **（可选）热量超标**：仅"日常饮食"板块显示
8. **点击确认记账**

提交后自动返回上一页。

### 3.2 费用来源说明

| 选择 | 影响 |
|------|------|
| 日常开支 | 金额计入"日常消耗进度"，影响每日可用额度 |
| 备用金 | 金额从备用金额度中扣除，不影响日常进度 |

> **提示**：一般日常吃饭、交通等选"日常开支"，大额应急消费如修电脑、看病等选"备用金"。

## 4. 账单管理

### 4.1 账单列表

通过底部导航「账单」进入。

**筛选功能**：

| 筛选项 | 选项 |
|--------|------|
| 来源 | 全部 / 日常开支 / 备用金 |
| 板块 | 全部 / 日常饮食 / 其他消费 |
| 标签 | 全部 / 大宗消费 / 冲动消费 |
| 搜索 | 按备注关键词搜索 |

- 按日期倒序排列，分页显示
- 每条账单显示：来源标签、板块、金额、备注、标签、热量标记
- 支持分页浏览，可切换每页条数

### 4.2 编辑账单

点击账单列表中的编辑按钮进入编辑页面：

- 可修改：金额、板块、来源、日期、备注、标签、热量标记
- **智能提交**：只提交实际变化的字段，无变更时提示"未检测到任何修改"
- 切换来源（日常↔备用金）后，预算计算自动调整

### 4.3 账单详情

点击账单可查看完整详情信息。

### 4.4 删除账单

列表中点击删除按钮即可删除，操作需确认。

## 5. 预算管理

### 5.1 设置预算

通过首页顶部「预算设置」进入。

**三个参数**：

| 参数 | 说明 | 示例 |
|------|------|------|
| 月度总预算 | 本月能支配的总金额 | ¥2,500 |
| 大额备用金 | 预留的应急额度，不参与日常计算 | ¥500 |
| 初始基数 | 月初已有消费（如上月透支转入） | ¥0 |

> **提示**：如果总预算 2500、备用金 500，则日常可消费额度为 2000。

### 5.2 预算详情页

从首页「日常消耗进度」卡片点击进入。

**页面包含**：

- **消耗进度条**：已花多少钱 / 日常有效预算，颜色根据进度变化
- **今日可用额度**：大字展示今日还可花多少钱，以及剩余天数
- **每日额度变化图**：近 30 天每日可用额度的柱状图
- **本月摘要**：
  - 日常开销有效预算
  - 已消费金额
  - 备用金剩余
  - 状态（正常 / 已透支）

### 5.3 预算计算原理

```
日常有效预算 = 月度总预算 - 备用金
每日可用 = (日常有效预算 - 日常已花) / 剩余天数
```

- 每天可用额度会随着已消费金额的增加而自动减少
- 如果透支了，进度条变红，显示透支金额

## 6. 备用金管理

### 6.1 概述

备用金是独立于日常预算的专属额度，用于大额或应急消费。记账时选择来源为"备用金"即从该额度扣减。

### 6.2 备用金详情页

从首页「💧 备用金」卡片点击进入。

**页面包含**：

- **状态卡片**：剩余 / 总额，已用金额
- **本月使用明细**：列出当月所有来源为"备用金"的账单，含日期、备注、金额
- **本月合计**：已用总额
- **近 6 月趋势图**：展示近 6 个月每月备用金使用金额的柱状图

### 6.3 备用金规则

- 备用金消费不影响日常消耗进度
- 备用金可透支，透支时显示红色警告
- 最低余额限制：`-备用金额度`（不会无限制透支）

## 7. 连续无冲动消费

### 7.1 概述

系统自动追踪你连续多少天没有冲动消费行为，形成正向反馈。

### 7.2 判定规则（每日凌晨自动执行）

| 昨日情况 | 结果 |
|----------|------|
| 有消费 + 无冲动标签 | 连续天数 +1 |
| 有消费 + 有冲动标签 | 连续天数归零 |
| 无消费 | 连续天数不变 |

- 同时自动更新最佳记录（历史最长连续天数）
- 突破历史记录时有提示

### 7.3 连续记录详情页

从首页「🔥 连续无冲动消费」卡片点击进入。

- **当前连续天数**：大字显示
- **最佳记录**：历史最高连续天数
- **60 天热力图**：颜色格子直观展示
  - 🟢 绿色 = 当天有记账但无冲动
  - 🔴 红色 = 当天有冲动消费
  - ⚪ 灰色 = 当天无记账记录

## 8. 宏观资产看板

通过底部导航「看板」进入，提供图表化的数据分析和统计。

### 8.1 数据卡片

页面顶部 4 个数据卡片：

| 卡片 | 说明 |
|------|------|
| 本月总支出 | 当月全部账单金额之和 |
| 日均支出 | 总支出 ÷ 有消费的天数 |
| 单笔最高 | 当月单笔最高支出金额 |
| 账单总数 | 当月账单总条数 |

### 8.2 消费板块分布

饼图展示"日常饮食"和"其他消费"的金额占比。

### 8.3 消费趋势

柱状图展示消费金额走势，支持切换：

- **月度视图**：近 6 个月每月总消费对比
- **每日视图**：近 30 天每日消费走势，冲动消费日用红色 📌 标记

### 8.4 行为标签统计

| 标签 | 统计内容 |
|------|----------|
| ⚡ 冲动消费 | 次数、金额、环比变化 |
| 📦 大宗消费 | 次数、金额、环比变化 |

环比变化带 ↑↓ 箭头指示，红色表示恶化，绿色表示改善。

## 10. 物价雷达

通过底部导航「物价」进入，帮助追踪日常消费品的价格变化。

### 10.1 物价看板

- **本月涨幅 Top 5**：价格变化最大的物品排行
- **价格走势图**：选择某个物品后，展示其历史价格折线图（含均价参考线）
- **近期物价记录**：最近录入的物品价格列表

### 10.2 录入物价

点击物价页面顶部「+ 录入物价」进入。

- 物品名称：支持输入或快捷选择（苹果、香蕉、猪肉、鸡胸肉、牛奶、咖啡等）
- 单价 + 单位：如 7.2 元/斤
- 购买日期：默认当天
- 购买地点：可选

提交后显示该物品的历史统计：均价、最高价、最低价、记录数。

### 10.3 物价智能提示

在记账时，如果备注中提到已有物价记录的物品，系统会显示温和的价格对比提示（如"上次 ¥5.8/斤，这次 ¥7.2/斤 ↑24%"），不影响记账流程。

## 12. 常见问题

### Q1：日常消耗进度和备用金的关系？

它们是相互独立的。日常预算用于三餐、交通等常规消费；备用金用于应急/大额消费。两者的消费分别从各自的额度中扣除，互不影响。

### Q2：如何把一笔消费从日常改为备用金？

进入账单列表 → 点击编辑 → 切换费用来源 → 保存。切换后预算计算会自动调整。

### Q3："本月总支出"和"日常消耗已花+备用金已花"为什么可能对不上？

在系统 V1.1 版本之前添加的费用来源功能，早期账单可能存在 source 字段为空的兼容数据。这类数据在预算计算中会被归入日常消耗。应该不会出现明显差异。

### Q4：连续无冲动天数怎么突然归零了？

每天凌晨系统会检查前一天是否有冲动消费（带 impulse 标签的账单）。如果有，连续天数就会归零重新开始。

### Q5：半个月可以修改预算吗？

可以。在预算设置页面修改后，每日可用额度会实时重新计算。如果调低预算导致已消费超过新预算，会显示透支状态但不影响正常记账。

### Q6：备用金可以为负数吗？

可以。备用金剩余最低为 `-备用金额度`，超过后不再继续减少。红色警告提示用户注意。

### Q7：物价雷达的数据从哪里来？

物价雷达的数据独立于记账，需要手动在物价页面录入。录入物品名、单价后，系统会自动追踪价格变化趋势。

### Q8：支持多用户吗？

系统支持注册多个用户，每个用户拥有独立的数据空间。数据通过 JWT 认证隔离。
