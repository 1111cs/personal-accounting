# 个人记账系统 - 产品需求文档

> Product Requirements Document
>
> **适配人群**：研究生 / 青年群体
>
> **平台形态**：Web 网页版（响应式，桌面 + 移动端适配）
>
> **版本**：V1.1 | **日期**：2026-06-14 | **状态**：已实施

---

## 1. 文档概述

### 1.1 项目背景

研究生群体普遍面临收入来源有限（父母生活费、奖学金、兼职等）、支出结构特殊（日常饮食高度依赖食堂/外卖）的财务现状。同时，研究生阶段是消费观念形成的关键时期，容易出现冲动消费、预算失控等问题。

市面现有记账应用多为移动 App 形态，功能臃肿、学习成本高，缺乏针对研究生群体的场景化功能。本系统选择 **Web 网页版**形态，优势在于：无需安装、跨平台通用（实验室电脑 / 个人笔记本 / 手机浏览器均可访问）、数据自主可控。

### 1.2 产品愿景

打造一款轻量、克制、懂研究生的个人财务伴侣——不制造焦虑，不强制自律，以"看见即改变"为核心理念，通过数据可视化和温和提醒，帮助用户建立健康的消费观念。

### 1.3 目标用户画像

| 维度 | 描述 |
|------|------|
| 身份 | 在读硕士研究生 |
| 年龄 | 22-30 岁 |
| 月收入 | 1000-5000 元（生活费 + 奖学金 + 兼职） |
| 消费特征 | 食堂/外卖为主，周期性大额支出（教材、会议），偶发性冲动消费 |
| 痛点 | 月底不知道钱花在哪、无法坚持记账、想省钱但控制不住冲动 |
| 使用场景 | 极简交互与正向反馈（追求"无感记录"，需要即时的情绪价值补偿） |
| 使用设备 | 实验室台式机、个人笔记本为主；偶尔手机浏览器访问 |

### 1.4 核心设计原则

- **极简优先**：单次记账操作不超过 3 步，核心流程 10 秒内完成
- **不归罪，只记录**：不因超支/透支惩罚用户，仅做数据呈现
- **温和提醒**：用数据说话，不做弹窗骚扰或强制打卡
- **日常与备用金分离**：备用金与日常消费通过 `source` 字段物理隔离，各自独立扣减
- **正向反馈驱动**：以成就徽章和进度条替代焦虑式催缴
- **首页克制**：首页仅展示核心指标卡片，详情通过点击进入二级页面

## 2. 功能模块详述

### 2.1 模块一：极简收支记录

#### 2.1.1 快捷录入

核心原则：必填项最小化，降低录入阻力。

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 金额 | 数字输入 | 是 | 支持小数点后两位，自动聚焦 |
| 消费板块 | 单选 | 是 | "日常饮食（food）" / "其他消费（other）" |
| 日期 | 日期选择 | 是 | 默认当日，可回溯修改 |
| 费用来源 | 分段选择 | 是 | "日常开支（daily）" / "备用金（reserve）"，默认日常开支 |
| 备注 | 文本 | 否 | 自由描述，限 100 字 |
| 行为标签 | 多选 | 否 | "大宗消费（big_spend）" / "冲动消费（impulse）" |
| 热量超标 | 勾选框 | 否 | 仅板块为"日常饮食"时显示 |

**录入流程**：选择板块 → 选择费用来源 → 输入金额 →（可选）勾选标签/热量 → 确认提交。

- 支持常用金额快捷按钮（¥15、¥25、¥50、¥100）
- 账单提交后返回上一页，展示录入成功提示

#### 2.1.2 费用来源（source）

每笔消费区分来源，实现日常预算与备用金的独立管理：

| 来源 | 值 | 说明 |
|------|------|------|
| 日常开支 | `daily` | 从月度日常预算中扣除，影响"日常消耗进度" |
| 备用金 | `reserve` | 从备用金额度中扣除，不影响日常进度 |

- 新建账单时默认选中"日常开支"
- 历史账单可在编辑时切换来源
- 切换来源后预算计算自动调整归属

#### 2.1.3 账单管理

- 账单列表：按日期倒序排列，分页展示
- 筛选功能：支持按关键词、板块、标签、费用来源、日期范围筛选
- 列表展示：显示来源标签（日常开支/备用金）、板块、金额、备注、行为标签、热量标记
- 点击编辑：跳转编辑页面，修改后保存（只提交变更字段，无变更时友好提示）
- 删除操作：单条删除，需确认
- 账单详情页：查看完整信息，支持跳转编辑

#### 2.1.4 行为标签系统

预设两种行为标签，用于消费行为自我觉察：

> **标签说明**
>
> - **大宗消费（big_spend）**：单笔 ≥ ¥100 的支出自动建议标记（可手动关闭）
> - **冲动消费（impulse）**：用户主动勾选，用于标记事后后悔的支出

- 标签在首页 Dashboard 的警示看板中高亮展示
- 冲动消费直接影响"连续不透支天数"
- 标签可组合使用（一笔消费可同时标记为"大宗 + 冲动"）

#### 2.1.5 健康辅线标签

在"日常饮食"板块中提供「热量超标」勾选框：

- 仅作客观记录，不设置强制运动打卡或卡路里计算
- 以列表项展示热量超标标记

### 2.2 模块二：动态预算管控

#### 2.2.1 月度预算设置

每月 1 日（或用户首次使用时）引导设定预算，核心参数：

| 参数 | 说明 | 示例 |
|------|------|------|
| 月度总预算 | 当月可支配总金额 | ¥2,500 |
| 大额备用金 | 固定预留额度，不计入日常消耗 | ¥500 |
| 本月已花基数（初始基数） | 手动输入的初始已消费基数（上月结转） | ¥0 |

支持月中修改预算，触发实时重算。

#### 2.2.2 每日可用额度计算

系统根据实时数据动态计算当日可用额度，核心公式如下：

```
日常有效预算 = 月度总预算 - 大额备用金
本月日常已消费 = SUM(source='daily' 的当月账单) + 初始基数
每日可用额度 = (日常有效预算 - 本月日常已消费) ÷ 本月剩余天数
```

设计要点：

- 备用金从"日常消耗盘子"中完全剔除，保持独立性
- 剩余天数 = 当月总天数 - 当前日期 + 1（含当日）
- 计算结果为负数时，显示"已透支 ¥XXX"
- 备用金消费（source='reserve'）不参与日常额度计算

#### 2.2.3 动态调整与透支保护

月中调低预算时的处理逻辑：

- 实时重算每日可用额度
- 若当前已花费 > 新预算：首页醒目标红显示"本月已透支"及透支金额
- 透支状态下不限制录入，不阻断功能，仅作视觉警示
- 调高预算无限制，即时生效

#### 2.2.4 透支逻辑

系统分别追踪两类透支：

| 透支类型 | 判定条件 | 前端表现 |
|----------|----------|----------|
| 日常透支 | 日常已消费 > 日常有效预算 | 进度条深红，显示"本月日常已透支 ¥XX" |
| 备用金透支 | 备用金消费 > 备用金额度 | 水滴红色，显示"备用金已透支" |
| 总透支 | 日常+备用金 > 月度总预算 | 预算详情页状态显示"已透支" |

#### 2.3.2 日常消耗进度条

```
进度 = 日常已消费 ÷ (月度总预算 - 大额备用金) × 100%
```

- 进度条颜色渐变：0-50% 绿色 → 50-80% 橙色 → 80-100% 红色 → >100% 深红
- 正常状态显示"今日可用 ¥XX.XX"
- 透支状态显示"⚠️ 本月日常已透支 ¥XX.XX"（红色）
- 详情页额外展示：每日额度变化曲线（30天柱状图）、预算摘要

#### 2.3.3 备用金状态指示器

首页以水滴卡片展示摘要，点击进入备用金详情页：

- 显示剩余金额 / 总额
- 颜色状态：安全（蓝色）/ 不足50%（橙色）/ 已耗尽（灰色）/ 透支（红色）
- 详情页展示：
  - 剩余/总额 + 已用金额
  - 本月使用明细（source='reserve' 的全部账单）
  - 近6月备用金使用趋势柱状图

#### 2.3.4 连续无冲动消费天数

- 默认目标：连续 30 天无冲动消费
- **逻辑**（每日凌晨定时任务执行）：
  - 昨日有消费记录 + 无冲动标签 → 连续天数 +1
  - 昨日有消费记录 + 有冲动标签 → 连续天数归零
  - 昨日无消费记录 → 连续天数不变
- 同时更新历史最佳记录
- 详情页展示：当前天数、最佳天数、近60天热力图（绿色=无冲动，红色=冲动日，灰色=无记录）
- **核心原则**：不归罪，只记录

#### 2.3.5 成就徽章系统

以游戏化徽章形式提供正向激励，首页仅显示最新解锁 + 总数概览：

| 徽章名称 | 触发条件 | 稀有度 |
|----------|----------|--------|
| 冷静一周 | 连续 7 天无冲动消费标记 | ★☆☆ |
| 储蓄达人 | 当月实际支出 ≤ 预算的 80% | ★★☆ |
| 铁打的自律 | 连续 30 天无冲动消费 | ★★★ |
| 三个月无透支 | 连续 3 个自然月无透支记录 | ★★★★ |
| 备用金守护者 | 连续 2 个月未动用备用金 | ★★☆ |
| 记账标兵 | 连续 30 天每天都有记账记录 | ★★☆ |
| 物价侦探 | 累计录入 20 条物价记录 | ★☆☆ |

- 成就墙页面集中展示所有徽章，未解锁的灰显并展示解锁条件
- 每日定时任务自动检查成就条件

### 2.4 模块四：宏观资产看板

#### 2.4.1 收支概览

- 饼图：展示"日常饮食"与"其他消费"的金额占比
- 柱状图：消费总额对比（支持月度/每日切换）
- 数据卡片：本月总支出、日均支出、单笔最高支出、账单总数

#### 2.4.2 消费趋势图

- 近 30 天消费柱状图：每日支出金额，冲动消费日红点标记
- 近 6 个月消费柱状图：月度支出总额对比
- 支持月度/每日视图切换

#### 2.4.3 标签统计

- 本月冲动消费次数 / 金额
- 本月大宗消费次数 / 金额
- 与上月的环比变化（↑↓ 箭头 + 百分比）

### 2.5 模块五：物价雷达（生活情报局）

#### 2.5.1 功能定位

帮助研究生建立日常高频消费品的"物价锚点"，对抗通货膨胀感知钝化。聚焦价格波动大、购买频率高的物品：水果、肉类、饮品。

**重要**：物价雷达与记账录入完全解耦，拥有独立的录入入口和展示页面。

#### 2.5.2 独立物价录入页

通过底部导航栏「物价」入口进入：

- 录入字段：物品名称、单价、单位（斤/个/瓶/杯）、购买日期、购买地点（可选）
- 支持快速选择常见物品（预设：苹果、香蕉、猪肉、鸡胸肉、牛奶、咖啡等）
- 支持从历史记录中一键复用物品名
- 录入后自动计算该物品的历史均价、最高价、最低价

#### 2.5.3 物价看板

- 首页以卡片形式展示「物价雷达 ▸」，点击进入完整物价页
- 完整页面包含：
  - 单物品价格走势折线图（带均价参考线）
  - 本月涨幅 Top 5 排行榜
  - 物品列表，点击展开该物品的历史价格明细
  - 近期录入的物品价格摘要

#### 2.5.4 智能提示（温和关联）

在记账录入页，若备注中提及已有物价记录的物品，系统：

- 温和提示当前价格与历史均价的差异（如"上次买苹果 ¥5.8/斤，这次 ¥7.2/斤 ↑24%"）
- **不阻断记账流程**，仅作信息参考
- 提示数据来源：用户在物价雷达模块中手动录入的价格记录

### 2.6 模块六：数据安全与导出

#### 2.6.1 数据存储

- 所有数据存储在 MySQL 数据库中

- 导出入口：设置页面

## 4. 核心公式

### 4.1 日常有效预算
```
日常有效预算 = 月度总预算 - 大额备用金
```

### 4.2 本月日常已消费
```
本月日常已消费 = SUM(source='daily' 的当月账单金额) + 初始基数
```

### 4.3 每日可用额度
```
每日可用额度 = max((日常有效预算 - 本月日常已消费) / 本月剩余天数, 0)
```

### 4.4 日常消耗进度
```
进度 = 本月日常已消费 / 日常有效预算
```

### 4.5 备用金剩余
```
备用金剩余 = max(备用金额度 - SUM(source='reserve' 的当月账单金额), -备用金额度)
```

### 4.6 总透支判定
```
总透支 = (本月日常已消费 + 备用金消费) > 月度总预算
```

### 4.7 日均支出（宏观看板）
```
日均支出 = 本月全部账单总金额 / 有消费记录的天数
```
